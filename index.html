Things I believe

Strong opinions, each one earned by something breaking.

  1. A prompt is not a control.If a rule matters, a script enforces it. The model can read the rule and still break it.
  2. Every claim should name the check behind it."Listed" means a live listing a script fetched, not an agent saying so.
  3. Agents get more reliable when they're allowed to do less.Anything deterministic moves out of the model loop and into plain code.
  4. Measure before you optimise.88% of my coding agent's usage was reading, while every token-saving tool fought over the other 12%.
  5. I'd rather change a setting than install a tool.A tool brings its own instructions, and on a bill that is mostly context, those cost you on every request.
